# Night Deck

Projeto original PokeIdle Deck em Windows Forms (.NET 8 + WebView2), com quatro contas, lives Twitch/Kick, extensões, recompra e recursos do projeto original.

Na aba **Actions**, abra **Night Deck Original - Windows** para baixar a versão portátil ou o instalador após a compilação.

Nota: o ícone original ainda não foi incluído neste commit; o aplicativo usa temporariamente o ícone padrão do Windows.
